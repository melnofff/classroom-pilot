# Classroom Pilot

Приложение преподавателя для компьютерного класса на Windows 11 x64. Компьютеры обозначаются номерами на мониторах, без привязки к ученикам.

## Скачать

[Последняя версия](https://github.com/melnofff/classroom-pilot/releases/latest)

- **Classroom.Teacher.exe** — на компьютер преподавателя.
- **Classroom.Agent.exe** — на каждый школьный компьютер.

Достаточно одного EXE. Устанавливать .NET или переносить библиотеки не нужно. Сохраните файл в постоянную папку с правом записи; приложение создаст рядом папку `data` для настроек и материалов.

## Подключить компьютер

1. Оба ПК должны быть в одной школьной сети. Запустите Teacher у преподавателя и Agent на школьном ПК. Помощника запускайте без прав администратора.
2. В панели преподавателя нажмите «Добавить компьютер», укажите номер с монитора и адрес преподавателя в школьной сети.
3. Вставьте полученную строку в помощника. Она действует 10 минут.
4. Дождитесь статуса «На связи». Можно открывать сайты, запускать Roblox Studio и передавать учебные файлы. Вход в аккаунт Roblox пока не автоматизирован.

При первой настройке сети на ПК преподавателя откройте PowerShell от администратора и выполните, указав фактический путь:

```powershell
& "C:\School\ClassroomPilot\Classroom.Teacher.exe" --configure-network
```

Затем закройте терминал администратора и запускайте панель обычным способом. Правило разрешает только это приложение в локальной подсети для частных и доменных сетей. Если сеть общедоступная или разделена на подсети, настройку уточните у школьного администратора.

## Обновить

- Преподаватель: кнопка «Проверить обновления» внизу панели.
- Помощник: «Проверить обновления…» в меню значка возле часов.

Обновление запускается по подтверждению, отдельно на каждом ПК. Нужен доступ к GitHub через интернет; аккаунт и токен GitHub на школьных ПК не нужны. Настройки и материалы сохраняются. Если новая версия не подтверждает первоначальный запуск, обновлятор пытается вернуть предыдущий EXE.

При переходе с версии без обновлятора один раз закройте приложение и замените EXE вручную, сохранив его прежнюю папку `data`. Не переносите `data` между разными компьютерами или пользователями Windows.

В этом репозитории размещаются готовые приложения и описание релизов. Исходный проект хранится отдельно.
